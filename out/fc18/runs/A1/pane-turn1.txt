
● I built the cup in the cup document. The
  profile is a sketch named CupProfile on the
  XZ plane, inside the Cup body, and a 360°
  revolve around the sketch's vertical axis
  (global Z) turns it into the solid.

  - Profile: a closed outline of the wall,
    floor and rim. It has four named
    dimensions and is fully constrained.
  - Parameters: the dimensions are linked to
    Params by expressions.
    - outer_radius is cup_diameter / 2.
    - height is cup_height.
    - side_wall and floor are both wall.
  - Placement: the base sits at z = 0 on the
    XY plane and the top is open.
  - Size: with the current values it is 60 mm
    across and 80 mm tall. The solid is valid
    and its volume is about 34,080 mm³, which
    matches my hand calculation.
  - Parameter test: I temporarily set
    cup_diameter to 80 and the width grew to
    80 mm with the shape still valid. I then
    set it back to 60.

  I didn't save the document, so save it if
