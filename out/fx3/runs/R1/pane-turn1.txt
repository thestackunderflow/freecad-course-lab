  If you run Claude Desktop on Windows but uvx

  Windows. Either:
  - Install uv on Windows (winget install

    typically

    Remember to double the backslashes in
    JSON. This is the better option if FreeCAD
    itself runs on Windows.
  - Or launch it through WSL:
  "command": "wsl.exe",
  "args": ["-e", "/home/maker/.local/bin/uvx",
  "freecad-mcp"]
    This only works if FreeCAD is reachable
    from inside WSL.
