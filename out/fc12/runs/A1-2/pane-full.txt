❯ My coat stand has 4 hooks that should be 60
  degrees apart on the front half, but one
  points into the wall. Fix it so the gap
  stays 60 when I change the number of hooks.

● I'll start by finding the coat stand model.

  Listed 1 directory (ctrl+o to expand)

  Called freecad 2 times (ctrl+o to expand)

● The pattern uses a hardcoded 240° span, so
  the four hooks sit 80° apart, but the unused
  hook_gap parameter (60°) should control
  that spacing, so I'm wiring the angle to it.
  · summary

  Called freecad (ctrl+o to expand)

● The four hooks are now 60° apart. They fan
  across the front half (0°, 60°, 120°, 180°),
  and none points into the wall.

  Cause: the PolarPattern was in "Extent" mode
  with a fixed 240° total angle. FreeCAD
  divides that across the gaps, so 4 hooks
  came out 80° apart and the last one ended at
  240°. The hook_gap cell in Params wasn't
  connected to anything.

  Fix: I set the pattern's Angle to the
  expression Params.hook_gap * (Params.hooks -
  1). Changing hooks now keeps the 60°
  spacing, and changing hook_gap changes the
  spacing.

  I tried 3, 4 and 5 hooks and each gave a
  valid single solid:

  ┌───────┬───────────────┐
  │ Hooks │ Pattern angle │
  ├───────┼───────────────┤
  │ 3     │ 120°          │
  ├───────┼───────────────┤
  │ 4     │ 180°          │
  ├───────┼───────────────┤
  │ 5     │ 240°          │
  └───────┴───────────────┘

  - Limit on hook count: at 60° spacing, 4
    hooks is the most that stays within the
    front half (180°). With 5 or more, the
    extra hooks go past the front half and
    toward the wall.
  - Single hook: a hook count of 1 gives a 0°
    pattern angle, which FreeCAD may reject. I
    didn't test it.
  - Saving: the change is made in the open
    FreeCAD document stand. I didn't save the
    file, so save it from FreeCAD if you want
    to keep it.
